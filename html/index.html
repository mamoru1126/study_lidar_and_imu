ROBOMECH2023 を読むための学習ノート

LiDAR と IMU で、欠けた地図の上でも迷わない自己位置推定を理解する

この教材は、点群と IMU の制約をウィンドウ最適化でまとめて解く自己位置推定の論文を、 数学の道具から順に積み上げて読み解くためのものです。各章に numpy だけで動く演習があり、 最後は論文の手法を 2D で再現します。

点群・IMU 制約のウィンドウ最適化に基づく既知地図上での 6DoF 姿勢推定
小出 健司, 大石 修士, 横塚 将志, 阪野 貴彦 (産総研) / ROBOMECH2023
論文 PDF を開く ・ ロードマップから始める

2D 再現実験の 1 シーン。灰色の点が事前地図で、右側の色付きの領域は地図を消してある。青い線が提案手法の推定軌跡、放射状の線が LiDAR のスキャン。

論文の中心にある 1 本の式

ウィンドウ内の状態 X について、4 種類の誤差の和を最小にします。

\[ F(\mathcal{X}) = \sum_{\mathbf{x}_i \in \mathcal{X}} \sum_{j=i-2}^{i-1} f^{P}(\mathbf{x}_i, \mathbf{x}_j) + \sum_{\mathbf{x}_i \in \mathcal{X}} f^{P}(\mathbf{x}_i, \mathcal{M}) + \sum_{\mathbf{x}_i \in \mathcal{X}} f^{I}(\mathbf{x}_{i-1}, \mathbf{x}_i) + C(\mathcal{X}) \]
フレーム同士のマッチング最新フレームを直前の 2 フレームと VGICP で比べる。→ 03 章
地図とのマッチングフレームを既知の地図点群と比べる。地図がない場所では自然に効かなくなる。→ 07 章
IMU 事前積分連続する状態の動きを IMU と整合させる。バイアスも推定。→ 04 章
周辺化因子ウィンドウから出た過去の情報を残す。→ 06 章

進め方

  1. 論文を一度ざっと読み、分からない言葉に印をつける。
  2. 01〜07 章を順に読み、各章の Python 演習を実行する。数式は演習の数値で確かめる。
  3. 08 章を横に置いて論文を読み直す。印をつけた言葉を全部説明できるか確認する。
  4. 余裕があれば 09 章を頼りに、著者の GLIM のコードで同じ部品を探す。

演習の環境

cd study_lidar_and_imu
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python exercises/check_env.py
